BaseModel¶

class marinade.fabm.base_model.BaseModel(model_name: str = '', repair_state: bool = False, repair_minfunc: callable = torch.clamp_min, repair_maxfunc: callable = torch.clamp_max, mask_func: callable = <function BaseModel.<lambda>>, device='cpu', dtype=torch.float64, *args, **kwargs)[source]¶

Base class for biosystem models.

Subclasses should be defined for specific models.

Instances of this base model will return zero sinking velocity and the forward step will not change the tracer concentrations.

If created by the constructor method, this model uses the default parameters. A model with custom parameters can be created from a .yaml file with model.create_model_from_yaml_file.

Parameters:

  • model_name (str, optional) – The name of the model. Defaults to “”.

  • repair_state (bool, optional) – Whether to repair invalid states. Defaults to False.

  • repair_minfunc (callable, optional) – Method for the lower bound of allowed values. Defaults to torch.clamp_min.

  • repair_maxfunc (callable, optional) – Method for the upper bound of allowed values. Defaults to torch.clamp_max.

  • device (str, optional) – The device where the tensors of the model should be stored. Defaults to “cpu”.

  • dtype (torch.dtype, optional) – The default data type of the model. Defaults to torch.float64.

get_vertical_movement(concentration: tensordict.TensorDict | torch.Tensor, dynamic_inputs: tensordict.TensorDict, *args, **kwargs) → torch.Tensor[source]¶

Compute velocity for vertical movement through the fluid for biological state variables.

Note that this method returns a zero sinking velocity. It should generally be overwritten by subclasses, in case they feature a non-zero sinking velocity.

For more complex models, the result might depend on the momentary state.

Parameters:

  • concentration (Union[TensorDict, torch.Tensor]) – Momentary concentrations of the model tracers. [batch, tracer, nlev]

  • dynamic_inputs (TensorDict) – Dict of additional inputs.

Returns:

Vertical movement of the model tracers.

[batch, tracer or 1, nlev] or [batch, tracer or 1, nlev + 1]

torch.Tensor
