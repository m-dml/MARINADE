DiffusionOperator¶

class marinade.gotm.diffusion.DiffusionOperator(bc_up_type: str, bc_down_type: str, bc_up_value: float | torch.Tensor, bc_down_value: float | torch.Tensor, implicitness: float = 1.0, allow_negative: bool = False, method: str = 'thomas', implicit_backward: bool = True, device: str = 'cpu', dtype='float64', *args, **kwargs)[source]¶

Diffusion operator class.

Should be initialized with the important numerical parameters and schemes for the simulation. Has a forward method for computing a single time step. Calling the operator object itself also calls its forward method.

The operator solves the one-dimensional diffusion equation:

\[\frac{\partial Y}{\partial t} = \frac{\partial}{\partial z}\left(\nu_Y\frac{\partial Y}{\partial z}\right) + Y L_{sour} + Q_{sour}\]
Parameters:

  • bc_up_type (str) – Type of upper boundary condition. “neumann” or “dirichlet”.

  • bc_down_type (str) – Type of lower boundary condition. “neumann” or “dirichlet”.

  • bc_up_value (Union[float, torch.Tensor]) – Value of upper boundary condition. Scalar or [batch, (tracer or 1)]

  • bc_down_value (Union[float, torch.Tensor]) – Value of lower boundary condition. Scalar or [batch, (tracer or 1)]

  • implicitness (float, optional) – Implicitness parameter. Defaults to 1.0.

  • allow_negative (bool, optional) – Allow negative tracer concentration values. Defaults to False.

  • method (str, optional) – Method for tridiagonal solver. One of (“thomas”, “paracr”, “linalg”). Defaults to “thomas”.

  • implicit_backward (bool, optional) – If True, uses custom backward method based on implicit differentiation. Defaults to True.

  • device (str, optional) – Device for torch computations. Defaults to ‘cpu’.

  • dtype (str, optional) – Data type for torch computations. Defaults to ‘float64’.

Forward function for time stepping operator.

Parameters:

  • concentration (Union[torch.Tensor, TensorDict]) – The initial tracer concentration field. Can be a TensorDict. Then this operator acts on concentration[“pelagic”]. This functionality exists because benthic (sediment) variables might be part of the tracer state, but they are only on the ground and do not diffuse. [batch, tracer, nlev]

  • dt (float) – Time step.

  • h (torch.Tensor) – Layer heights. [batch, (tracer or 1), nlev]

  • nu (torch.Tensor) – Diffusivity field at cell faces. [batch, (tracer or 1), nlev+1]

  • lsource (torch.Tensor, optional) – Linear source term. Defaults to None.

  • qsource (torch.Tensor, optional) – Constant source term. Defaults to None.

  • bc_up_value (Union[float, torch.Tensor], optional) – Upper boundary condition value. Optional. If None, the value specified at operator initialization is used. Defaults to None. Scalar or [batch, (tracer or 1)]

  • bc_down_value (Union[float, torch.Tensor], optional) – Lower boundary condition value. Optional. If None, the value specified at operator initialization is used. Defaults to None. Scalar or [batch, (tracer or 1)]
