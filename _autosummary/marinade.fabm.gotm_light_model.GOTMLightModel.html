GOTMLightModel¶

class marinade.fabm.gotm_light_model.GOTMLightModel(a: float | torch.Tensor, g1: float | torch.Tensor, g2: float | torch.Tensor, tempmean_method: str | None = None, compute_surface_par: bool = True, model_name: str = 'light', device='cpu', dtype=torch.float64, *args, **kwargs)[source]¶

This class provides a light model that can be used with biogeochemical models. It takes the incoming short-wave radiation as input and computes the photosynthetically active radiation at the water surface and in the water.

This model can be coupled to another biomodel through GOTMLightModel.couple(model), see below.

Some biosystem models require temporal light averages, typically over 24 hours. These can be computed with this light model with a moving 24 hour time window or as exponential smoothing.

Parameters:

  • a (Union[float, torch.Tensor]) – Fraction of the incoming radiation that is not photosynthetically active.

  • g1 (Union[float, torch.Tensor]) – Light extinction length for radiation that is not photosynthetically active.

  • g2 (Union[float, torch.Tensor]) – Light extinction length for photosynthetically active radiation.

  • tempmean_method (str, optional) – Method for evaluating temporal means of the light fields. Possible options: (“running_mean_strict”, “exponential_mean”). Defaults to None.

  • compute_surface_par (bool, optional) – If False, the surface photoactive radiation is set to the value of the full light input. If True, it is reduced according to the a coefficient. Defaults to True.

  • model_name (str, optional) – The name of the model. Defaults to “light”.

  • device (str, optional) – The device where the tensors of the model should be stored. Defaults to “cpu”.

  • dtype (torch.dtype, optional) – The default data type of the model. Defaults to torch.float64.

Compute the light distribution based on incoming surface radiation and water and tracer attenuation.

Parameters:

  • concentration (TensorDict) – The current tracer concentrations. Should have the field: - “pelagic”: The pelagic tracer concentrations. [batch, tracer, nlev]

  • dt (float) – The time step of the simulation.

  • dynamic_inputs (TensorDict) – Dict of inputs. Should have the fields: - “I_0”: Incoming surface radiation. [batch] - “zeta”: Water surface elevation. [batch] - “z”: Vertical coordinates at cell centers. [batch, nlev] - “h”: Vertical layer heights. [batch, 1, nlev] or [batch, nlev]

Returns:

The new tracer concentration field. Adds/updates the fields:

  • ”light_swr”: Shortwave radiation. [batch, nlev]

  • ”light_par”: Photosynthetically active radiation. [batch, nlev]

  • ”light_par0”: Surface photosynthetically active radiation. [batch, nlev]
