runge_kutta_4¶

marinade.util.ode_solvers.runge_kutta_4(concentration: tensordict.TensorDict | torch.Tensor, dt: float | torch.Tensor, dynamic_inputs: tensordict.TensorDict, rhs_function: Callable, *args, **kwargs)[source]¶

Fourth-order explicit Runge-Kutta scheme according to:

\[\begin{split}k_1 &= f(c^n) \\ k_2 &= f(c^n + \frac{\Delta t}{2} k_1) \\ k_3 &= f(c^n + \frac{\Delta t}{2} k_2) \\ k_4 &= f(c^n + \Delta t\, k_3) \\ c^{n+1} &= c^n + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)\end{split}\]
Parameters:

  • concentration (Union[TensorDict, torch.Tensor]) – The current state

  • dt (Union[float, torch.Tensor]) – The time step

  • dynamic_inputs (TensorDict) – Inputs to the model, e.g. temperature, salinity, …

  • rhs_function (Callable) – Right-hand side function \(f\)

Returns:

The new state

Return type:

(TensorDict or torch.Tensor)
