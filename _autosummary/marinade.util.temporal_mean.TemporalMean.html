TemporalMean¶

class marinade.util.temporal_mean.TemporalMean(variable: str, period: float, resolution: float, use_incomplete_result: bool = True, *args, **kwargs)[source]¶

Class for keeping track of average values of variables.

Each TemporalMean keeps track of one variable / key in a TensorDict specified at initialization.

Note that all information on the variable history is stored in the state itself. Thus, an instance of this class does not need to be applied in a “chronological order” for keeping track of the mean values.

Parameters:

  • variable (str) – The name of the variable to average.

  • period (float) – The period over which to compute the means.

  • resolution (float) – Length of time bins over which mean values are stored in order to reduce memory costs.

  • use_incomplete_result (bool, optional) – Whether to take means over smaller periods for shorter histories. Defaults to True.
