diffuse_at_center¶

marinade.gotm.diffusion.diffuse_at_center(value: torch.Tensor, dt: float, h: torch.Tensor, nu: torch.Tensor, bc_up_type: str, bc_down_type: str, bc_up_value: float | torch.Tensor, bc_down_value: float | torch.Tensor, implicitness: float = 1.0, allow_negative: bool = False, lsource: torch.Tensor | None = None, qsource: torch.Tensor | None = None, method: str = 'thomas', implicit_backward: bool = True) → torch.Tensor[source]¶

Diffuse a tracer at layer centers using GOTM diffusion operator.

Solves the one-dimensional diffusion equation:

\[\frac{\partial Y}{\partial t} = \frac{\partial}{\partial z}\left(\nu_Y\frac{\partial Y}{\partial z}\right) + Y L_{sour} + Q_{sour}\]
Parameters:

  • value (torch.Tensor) – Initial tracer concentration. [batch, tracer, nlev]

  • dt (float) – Time step.

  • h (torch.Tensor) – Layer heights. [batch, 1, nlev]

  • nu (torch.Tensor) – Turbulent diffusivities. [batch, 1, nlev+1]

  • bc_up_type (str) – Type of the upper boundary condition. “neumann” or “dirichlet”.

  • bc_down_type (str) – Type of the lower boundary condition. “neumann” or “dirichlet”.

  • bc_up_value (Union[float, torch.Tensor]) – Value of the upper boundary condition. Scalar or [batch, (tracer or 1)]

  • bc_down_value (Union[float, torch.Tensor]) – Value of the lower boundary condition. Scalar or [batch, (tracer or 1)]

  • implicitness (float, optional) – The implicitness of the numerical scheme. Defaults to 1.0.

  • allow_negative (bool, optional) – Whether to allow negative values of the tracer. Defaults to False.

  • lsource (torch.Tensor, optional) – Linear source term. Defaults to None. [batch, (tracer or 1), nlev]

  • qsource (torch.Tensor, optional) – Constant source term. Defaults to None. [batch, (tracer or 1), nlev]

  • method (str, optional) – Method for tridiagonal solver. One of (“thomas”, “paracr”, “linalg”). Defaults to “thomas”.

  • implicit_backward (bool, optional) – If True, uses custom backward method based on implicit differentiation. Defaults to True.

Returns:

Final tracer concentration, shape (batch, nlev)

Return type:

torch.Tensor
