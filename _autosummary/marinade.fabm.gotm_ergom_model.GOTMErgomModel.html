GOTMErgomModel¶

class marinade.fabm.gotm_ergom_model.GOTMErgomModel(ode_method: str, fluff: bool = False, model_name: str = 'ergom', device: str = 'cpu', dtype: torch.dtype = torch.float64, *args, **kwargs)[source]¶

This class describes the biosystem model ERGOM introduced by Neumann and Fennel.

If created by the constructor method, this model uses the same default parameters as the version of this model provided by FABM. A model with custom parameters can be created from a .yaml file with GOTMErgomModel.create_model_from_yaml_file.

Parameters:

  • ode_method (str) – The numerical method for solving the tracer ODE. Supported schemes: (“FE”: Forward Euler, “RK2”: 2nd order Runge-Kutta, “RK4”: 4th order Runge-Kutta)

  • fluff (bool, optional) – Whether to use an additional benthic tracer. Defaults to False.

  • model_name (str, optional) – The name of the model. Defaults to “ergom”.

  • device (str, optional) – The device where the tensors of the model should be stored. Defaults to “cpu”.

  • dtype (torch.dtype, optional) – The default data type of the model. Defaults to torch.float64.
