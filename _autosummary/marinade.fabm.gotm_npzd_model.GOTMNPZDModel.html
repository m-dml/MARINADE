GOTMNPZDModel¶

class marinade.fabm.gotm_npzd_model.GOTMNPZDModel(ode_method: str, model_name: str = 'npzd', device: str = 'cpu', dtype: torch.dtype = torch.float64, *args, **kwargs)[source]¶

This class describes a toy biosystem model with four tracers: Nutrients, phytoplankton, zooplankton and detritus.

If created by the constructor method, this model uses the same default parameters as the version of this model provided by FABM. A model with custom parameters can be created from a .yaml file with GOTMNPZDModel.create_model_from_yaml_file.

Parameters:

  • ode_method (str) – The numerical method for solving the tracer ODE. Supported schemes: (“FE”: Forward Euler, “RK2”: 2nd order Runge-Kutta, “RK4”: 4th order Runge-Kutta)

  • model_name (str, optional) – The name of the model. Defaults to “npzd”.

  • device (str, optional) – The device where the tensors of the model should be stored. Defaults to “cpu”.

  • dtype (torch.dtype, optional) – The default data type of the model. Defaults to torch.float64.
