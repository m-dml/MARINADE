BioModel¶

class marinade.fabm.bio_model.BioModel(ode_method, device='cpu', dtype=torch.float64, *args, **kwargs)[source]¶

Extension of the base class for biosystem models that implements crucial methods for modelling biogeochemical processes.

Subclasses should be defined for specific models. They should implement the following methods: - do: Calculate derivative vector for pelagic tracer concentrations. - do_surface: Optional. Calculate surface derivatives for pelagic tracer concentrations. - do_bottom: Optional. Calculate bottom derivatives for pelagic tracer concentrations and derivatives for

benthic fields.

do_repair_state(concentration: tensordict.TensorDict | torch.Tensor)[source]¶

Repair function for the states. In many models, there are maximal or minimal allowed values for certain tracers. In particular, there might be a positivity constraint.

Note that the variable self.repair_state (bool) indicates whether to do repairs. Only if True, this function applies corrections.

The maximum and minimum allowed values should be specified by the model as self.maximum/self.minimum (for tensor states) or self.maximum_td/self.minimum_td (for TensorDict states).

The correction functions should be stored as self.repair_minfunc or self.repair_maxfunc, e.g. torch.clamp_min.

Parameters:

concentration (Union[TensorDict, torch.Tensor]) – Current state. Can be a tensor or TensorDict with key ‘pelagic’ for the submerged tracers.

Returns:

The repaired state

Return type:

Union[TensorDict, torch.Tensor]

get_vertical_movement(concentration: tensordict.TensorDict | torch.Tensor, dynamic_inputs: tensordict.TensorDict, *args, **kwargs)[source]¶

Compute vertical movement through the fluid for biological state variables.

The default implementation for subclasses of BioModel returns a constant sinking velocity per tracer. It should be stored during model initialization as self.ws with the shape [1, tracer, 1].

Parameters:

  • concentration (Union[TensorDict, torch.Tensor]) – Momentary concentrations of the model tracers. [batch, tracer, nlev]

  • dynamic_inputs (TensorDict) – Dict of additional inputs.

Returns:

Constant vertical velocity as defined at model initialization.

[batch, tracer or 1, nlev]
