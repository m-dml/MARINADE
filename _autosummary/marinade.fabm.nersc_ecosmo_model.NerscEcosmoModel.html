NerscEcosmoModel¶

class marinade.fabm.nersc_ecosmo_model.NerscEcosmoModel(use_cyanos: bool, use_fish: bool, couple_co2: bool, use_chl: bool, community_export: bool, ode_method: str, turn_on_additional_diagnostics: bool = False, use_corrected_bioc: bool = False, model_name: str = 'ecosmo', device='cpu', dtype: torch.dtype = torch.float64, *args, **kwargs)[source]¶

This class describes the biosystem model ECOSMO developed by the Nansen center and Hereon.

If created by the constructor method, this model uses the same default parameters as the version of this model provided by FABM. A model with custom parameters can be created from a .yaml file with NerscEcosmoModel.create_model_from_yaml_file.

Parameters:

  • use_cyanos (bool) – Whether to include cyanobacteria as a tracer in the model or not

  • use_fish (bool) – Whether to include fish and macrobenthos in the model.

  • couple_co2 (bool) – Whether to couple this model with a CO2 model. Currently not supported.

  • use_chl (bool) – Whether to use additional tracers associated with chlorophyll.

  • ode_method (str) – The numerical method for solving the tracer ODE. Supported schemes: (“FE”: Forward Euler, “RK2”: 2nd order Runge-Kutta, “RK4”: 4th order Runge-Kutta)

  • turn_on_additional_diagnostics (bool, optional) – Legacy parameter that has no effect. Defaults to False.

  • use_corrected_bioc (bool, optional) – Whether to use a suggested correction to the model concerning the parameter “Exphy” or “phyto self-shading”. If this is True, the parameter depends on use_chl. Defaults to False.

  • model_name (str, optional) – The name of the model. Defaults to “ecosmo”.

  • device (str, optional) – The device where the tensors of the model should be stored. Defaults to “cpu”.

  • dtype (torch.dtype, optional) – The default data type of the model. Defaults to torch.float64.

do(concentration: tensordict.TensorDict, dynamic_inputs: tensordict.TensorDict, *args, **kwargs) → tensordict.TensorDict[source]¶

Calculate right-hand side of biological time step ODE as a vector with temporal derivatives.

Parameters:

  • concentration (TensorDict) – The current system state. Should have the fields “pelagic” and “benthic”. If this model is coupled with a light model, concentration should also have the fields “light_par”, “light_par0” and also “light_par_mean” and “light_par0_mean” for the temporal mean values, depending on the mode of time averaging in the light model. The time averages can also be provided in dynamic_inputs.

  • dynamic_inputs (TensorDict) – Time-dependent model inputs. Should have the fields “taub”, “temp”, “salt”. If this model is not coupled to a light model, should also have the corresponding light fields “par”, “mean_par”, “mean_surface_par”.

Returns:
