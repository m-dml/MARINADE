PassiveModel¶

class marinade.fabm.passive_model.PassiveModel(ws: torch.Tensor | float = 0.0, device: str = 'cpu', dtype: torch.dtype = torch.float64, *args, **kwargs)[source]¶

This class provides a very simple biosystem model for an inert tracer.

There are no biogeochemical reactions, the tracer stays conserved and only sinks relative to the water with a constant velocity. The sinking velocity is the one model parameter of this class.

classmethod create_model_from_yaml_file(path_fabm: str, path_gotm: str, device: str = 'cpu', dtype: str | torch.dtype = torch.float64, *args, **kwargs)[source]¶

Creates a passive_model instance based on .yaml configuration files.

For this model, the required keys in the gotm yaml file are: - “grid/nlev”: The number of vertical layers. - “instances/<instance_name>/model”: Should be “bb/passive” for the passive model - “instances/<instance_name>/parameters/vertical_velocity”: Sinking velocity - “instances/<instance_name>/initialization/<tracer_name>”: Initial (homogeneous) concentrations for the

tracers. The values are not actually used, but the tracer names are stored in model.tracer_names and the velocity field is initialized with the tracer dimension equal to the number of tracers.

Parameters:

  • path_fabm (str) – Path to the FABM .yaml configuration file

  • path_gotm (str) – Path to the GOTM .yaml configuration file

  • device (str, optional) – Torch device. Defaults to “cpu”.

  • dtype (Union[str, torch.dtype]) – Torch data type. Defaults to torch.float64.

Returns:

The generated model
