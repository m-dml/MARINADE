TracerSimulationOperator¶

class marinade.gotm.gotm.TracerSimulationOperator(bc_up_type_dif: str, bc_down_type_dif: str, bc_up_value_dif: float | torch.Tensor, bc_down_value_dif: float | torch.Tensor, bc_up_type_adv: str, bc_down_type_adv: str, bc_up_value_adv: torch.Tensor, bc_down_value_adv: torch.Tensor, scheme_adv: str, conserve: bool = False, implicitness: float = 1.0, allow_negative: bool = False, freshwater_impact: bool = False, method_tridiag: str = 'thomas', implicit_backward_tridiag: bool = True, model: BaseModel | None = None, device: str = 'cpu', dtype='float64', *args, **kwargs)[source]¶

Simulation operator class for combined tracer advection, diffusion and BGC reactions.

Should be initialized with the important numerical parameters and schemes for the simulation. Has a forward method for computing a single time step. Calling the operator object itself also calls its forward method.

Also has an integrate method for a complete rollout.

Parameters:

  • bc_up_type_dif (str) – Type of upper boundary condition for diffusion. “neumann” or “dirichlet”.

  • bc_down_type_dif (str) – Type of lower boundary condition for diffusion. “neumann” or “dirichlet”.

  • bc_up_value_dif (Union[float, torch.Tensor]) – Value of upper boundary condition for diffusion.

  • bc_down_value_dif (Union[float, torch.Tensor]) – Value of lower boundary condition for diffusion.

  • bc_up_type_adv (str) – Type of upper boundary condition for advection (“flux”, “value”, “oneSided”, “zeroDivergence”).

  • bc_down_type_adv (str) – Type of lower boundary condition for advection (“flux”, “value”, “oneSided”, “zeroDivergence”).

  • bc_up_value_adv (torch.Tensor) – Value for upper boundary condition for advection.

  • bc_down_value_adv (torch.Tensor) – Value for lower boundary condition for advection.

  • scheme_adv (str) – Advection limiter scheme to use (“superbee”, “p2_pdm”, “splmax13”, “muscl”, “central”, “p2”).

  • conserve (bool, optional) – Whether to use the conservative form of the advection equation for the advection due to fluid motion (sinking is always conservative). Defaults to False.

  • implicitness (float, optional) – Implicitness parameter. Defaults to 1.0.

  • allow_negative (bool, optional) – Allow negative tracer concentration values. Defaults to False.

  • freshwater_impact (bool, optional) – Whether to consider the impact of freshwater dilution. Defaults to False.

  • method_tridiag (str, optional) – Method for tridiagonal solver. One of (“thomas”, “paracr”, “linalg”). Defaults to “thomas”.

  • implicit_backward_tridiag (bool, optional) – If True, uses custom backward method based on implicit differentiation. Defaults to True.

  • model (NPZDModel, optional) – Nutrient-phytoplankton-zooplankton-detritus model for biogeochemical transport. If None, no biogeochemical processes (including sinking) are evaluated. Defaults to None.

  • device (str, optional) – Device for torch computations. Defaults to ‘cpu’.

  • dtype (str, optional) – Data type for torch computations. Defaults to ‘float64’.

Compute a rollout of the transport operator from initial state and forcing conditions. The shape of the forcing fields in the time axis determines the rollout length.

Note that \(h^{n+1}\), \(\nu^n\), and \(w^n\) are used for the computation of the concentrations at time step \(n+1\).

Parameters:

  • init_state (Union[torch.Tensor, TensorDict]) – The initial state. Can be a TensorDict. Then this operator acts on init_state[“pelagic”]. This functionality exists because benthic (sediment) variables might be part of the tracer state, but they are only on the ground and do not advect or diffuse. [batch, tracer, nlev]

  • dt (float) – The time step for the simulation

  • h (torch.Tensor) – The layer heights. [batch, time, 1, nlev]

  • nu (torch.Tensor) – The diffusivity field. [batch, time, 1, nlev+1]

  • bc_up_value (torch.Tensor, optional) – Value of upper boundary condition. If None, defaults to the value set at initialization. Defaults to None.

  • bc_down_value (torch.Tensor, optional) – Value of lower boundary condition. If None, defaults to the value set at initialization. Defaults to None.

  • lsource (torch.Tensor, optional) – Linear source term (optional). Defaults to None. [batch, time, (tracer or 1), nlev]

  • qsource (torch.Tensor, optional) – Constant source term (optional). Defaults to None. [batch, time, (tracer or 1), nlev]

  • w (torch.Tensor, optional) – Vertical fluid velocity component. Defaults to None. [batch, time, (tracer or 1), nlev+1]

  • dilution (torch.Tensor, optional) – Freshwater influx due to precipitation (positive) or evaporation (negative). Has to be provided if freshwater_impact was set to true at initialization of this operator. Defaults to None. [batch, time, 1]

  • dynamic_inputs (TensorDict, optional) – Additional inputs for the biogeochemical time step, if defined. Should have the shared batch size [batch, time].

Returns:

The integrated tracer concentrations. [batch, time, tracer, nlev]

Return type:

Union[torch.Tensor, TensorDict]
