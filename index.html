Documentation of MARINADE¶

MARINADE is a set of differentiable re-implementations of diffusion and advection operators from GOTM and marine biogeochemical models inspired by FABM.

Full documentation at https://m-dml.org/MARINADE/

Demonstrations of MARINADE and its support for automatic differentiation can be found in the notebooks folder. For instance, the following illustration from the sensitivity analysis notebook visualizes parameter sensitivities computed with MARINADE-NPZD:

MARINADE includes:

  • An implicit or semi-implicit vertical diffusion operator using a tridiagonal solver (re-implementation from GOTM with added tridiagonal solver options)

  • An explicit vertical advection operator (re-implementation from GOTM)

  • Re-implementations of biogeochemical (BGC) models:

    • The prototypical NPZD model introduced by Burchard et al. (2005) (GitHub)

    • The FABM version of ERGOM ported by Gennadi Lessin (GitHub)

    • ECOSMO II by Daewel and Schrum (2013) (without fish)

    • The GOTM light model (GitHub)

    • As well as an extendable base class for BGC models

  • A coupling operator for advection, diffusion and BGC operators

Our example notebooks include (but are not limited to):

  • Usage of vertical advection, diffusion and BGC operators (test_gotm_operators.ipynb)

  • Sensitivity analysis and finite difference approximation for NPZD model (sensitivity_analysis_fda_npzd.ipynb)

  • Joint state-parameter estimation in observing system simulation experiment with 4D-Var (4DVar_adda_npzd.ipynb)

Installation¶

To install you have to clone the repository and install it with pip:

git clone https://github.com/m-dml/MARINADE
cd MARINADE
pip install -e .

Technical Info¶

We use a custom backward method for the tridiagonal solver used by our implicit diffusion operator (see documentation).
